# WWI CEF War Diary Archive

A public, searchable archive of transcribed First World War war diaries of the
Canadian Expeditionary Force — built from the digitized diaries held by
Library and Archives Canada (CEF war diaries, RG9-III-D-3, finding aid 9-52).

## What is here

- `diaries/<unit-slug>/` — faithful transcriptions of each unit's war diary,
  one folder per unit, plus the structured index entries extracted from it.
- `index/INDEX.md` — the master searchable index, rebuilt daily: every entry
  with date, unit, location, people named, companies/platoons, casualties,
  movements, and what happened, with a pointer to its transcript.
- Public website (searchable front door to this repo):
  https://muse.ai/s/wwi-cef-war-diary-archive-xrxs6w4zxuxh1xsxh/EMFqj0vt8wEoU-qVCmKlH7-Dq22T01vTLzZP0EJdsMA

## Sources and licensing

The diaries themselves are century-old Canadian government records held by
Library and Archives Canada. Every transcription links back to the original
page images at LAC so anyone can check it against the source.

- Source diaries: public domain (Crown records, 1914–1919).
- Transcriptions and index in this repo: released under CC0 1.0 Universal
  (see `LICENSE`) — free to use for any purpose, no permission needed.

## Accuracy

Transcriptions are faithful to the original pages. Anything illegible or
uncertain is marked `[uncertain]` — names are never guessed. Corrections are
welcome: open an issue or a pull request naming the diary, page, and the
LAC image it corrects.

## Status

Transcription is ongoing — new unit diaries are added daily until the full
set of 467 diaries is complete. As of 28 Oct 2026: 33 diaries complete, 3 more
in progress, 23,313 index entries. See `index/INDEX.md` for current coverage.
